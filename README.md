📊 Project Overview
This project was created as part of a 2-day workshop on Data Analysis and Visualization using AI tools.
The project focused on cleaning and analyzing raw data using Python and creating meaningful visualizations from the cleaned dataset.

🛠️ Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Data Studio
- AI Tools

🔍 Data Analysis Process

1. Imported the dataset
2. Cleaned and preprocessed the data
3. Analyzed the cleaned dataset
4. Created visualizations using Python
5. Identified patterns and relationships in the data
6. Created an interactive dashboard using Data Studio

📈 Visualizations
The project includes:
- Scatter Plot – Discount Percentage vs Revenue
- Correlation Heatmap
- Top 10 Products by Revenue
- Monthly Revenue Trend

📊 Dashboard
An interactive dashboard was created using Data Studio to present the analyzed data in a visual and easy-to-understand format.

## 🎯 Learning Outcome

This workshop provided hands-on experience in transforming raw data into clean datasets, visualizations and meaningful insights using Python and AI-assisted tools.
